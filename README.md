# Magic 8 Ball Chatbot

A simple browser-based chatbot that looks and responds like a classic Magic 8 Ball.

## Features

- Magic 8 Ball style visual design
- Animated shake effect
- Random responses for user questions
- Chat log with recent questions and answers

## Run it locally

Open `index.html` in a browser, or run a simple local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure
- `style.css` — design and animations
- `script.js` — Magic 8 Ball logic
